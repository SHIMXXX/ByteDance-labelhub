## 成员 A 路线图（前台主链路 Owner）

## 总目标
负责把用户可见的主流程稳定跑通，并在当前 MVP 基础上逐步升级到更贴近题目验收的产品形态：
- 当前 MVP：Owner 建任务 → 搭模板 → 发布；Labeler 领任务 → 作答 → 保存草稿 → 提交；Reviewer 查看 / 通过 / 打回；Owner JSON / CSV 导出
- 后续升级：补齐真实 Designer / Renderer、任务广场检索、多题标注工作台、打回后修改重提、审核配置、导出配置与答辩交付物
